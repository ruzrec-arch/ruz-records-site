# Ruz Records — Site Oficial

> *for artists, for the future.*

Site oficial da **Ruz Records**, gravadora independente especializada em Phonk, Brazilian Phonk e Brazilian Funk. Fundada em novembro de 2025 por Ruz.

---

## 🌐 Acesso

**[ruzrec-arch.github.io/ruz-records-site](https://ruzrec-arch.github.io/ruz-records-site/)**

---

## 🗂️ Estrutura

```
index.html     → arquivo único do site (HTML + CSS + JS inline)
og-image.jpg   → imagem de capa para redes sociais
README.md      → este arquivo
```

## ✦ Funcionalidades

- **5 idiomas** — Inglês, Português, Espanhol, Italiano e Alemão (CH)
- **Formulário Send Demo** — integrado ao Telegram Bot (@RuzDemoBot)
- **Design responsivo** — adaptado para desktop e mobile
- **SEO otimizado** — meta tags, Open Graph e Twitter Card
- **Favicon** circular com logo RUZ
